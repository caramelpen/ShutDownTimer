ShutDownTimer
=============

概要
----
ShutDownTimer は、指定時刻または指定した経過時間後に Windows を強制シャットダウンするシンプルなデスクトップアプリケーションです。

Requirements
------------
- Windows
- .NET Framework 4.0
- Visual Studio（ビルドや編集には推奨）

ビルド方法
---------
1. ソリューションファイル (ShutDownTimer.sln) を Visual Studio で開きます。
2. ビルド -> ソリューションのビルド を実行します。

実行方法
--------
1. アプリを起動します。
2. 「指定経過時間」または「指定時刻」を選択します。
3. 時間（時間・分）を選択し、「開始」ボタンを押します。
4. 設定時刻に達すると shutdown.exe を呼び出して強制シャットダウンを実行します。

注意事項
--------
- shutdown.exe を直接呼び出しているため、シャットダウンは即時に行われます。テスト時は短時間の待ちで試すか仮想環境での確認を推奨します。
- 管理者権限や UAC の影響で動作が変わる場合があります。必要に応じて管理者権限で実行してください。
- 本ソフトは作業中のデータを保存せずにシャットダウンするため、重要なデータは事前に保存してください。

開発・修正箇所（主なファイル）
---------------------------
- UI/f01_Main.cs: メインの UI と動作ロジック
- UI/f01_Main.Designer.cs: フォームのデザイナ定義
- Common/Util/clsUtil.cs: shutdown.exe を呼び出す処理
